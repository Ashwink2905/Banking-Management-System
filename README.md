# Banking Management System

Java console-based project for Module 03 - Object-Oriented Programming in Java.

## Features
- Account details
- Deposit money
- Withdraw money
- Balance checking
- Transaction history
- Minimum balance validation

## OOP Concepts Used
- Class and Object
- Constructor
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
- Interface
- Method Overriding
- Access Modifiers
- ArrayList

## Requirements
- Java JDK 8 or later
- VS Code or any Java IDE

## Run
```bash
javac BankingManagementSystem.java
java BankingManagementSystem
```
